# Contributing to Digital Ophthalmology Clinical Record System (DOCRS)

Thank you for your interest in contributing to **DOCRS**! We welcome contributions from developers, UI/UX designers, and medical software enthusiasts.

---

## 🚀 How to Contribute

### 1. Fork & Clone the Repository

1. **Fork** the repository on GitHub by clicking the **Fork** button at the top right.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Digital-Ophthalmology-Clinical-Record-System.git
   cd Digital-Ophthalmology-Clinical-Record-System
   ```

### 2. Create a Feature Branch

Create a new branch with a descriptive name for your feature or bug fix:
```bash
git checkout -b feature/your-feature-name
```
*Example:* `git checkout -b feature/iop-charting-widget` or `git checkout -b fix/prescription-pdf-overflow`

### 3. Code Standards & Guidelines

- **Flutter / Dart Style**: Follow official [Effective Dart](https://dart.dev/effective-dart) guidelines.
- **Static Analysis**: Ensure `dart analyze` passes with zero errors before submitting:
  ```bash
  dart analyze
  ```
- **Automated Tests**: Run existing unit and widget tests:
  ```bash
  flutter test
  ```

### 4. Commit Your Changes

Write clear, concise commit messages:
```bash
git add .
git commit -m "Feat: Add intraocular pressure trend chart widget"
```

### 5. Push & Open a Pull Request

1. Push your feature branch to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
2. Go to the original [Digital-Ophthalmology-Clinical-Record-System Repository](https://github.com/ArceasCalzada/Digital-Ophthalmology-Clinical-Record-System).
3. Click **Pull Requests** -> **New Pull Request**.
4. Select your branch and submit the Pull Request with a brief explanation of your changes.

---

## 🐛 Reporting Issues & Bugs

If you find a bug or have a feature request:
1. Open a new issue under the [Issues Tab](https://github.com/ArceasCalzada/Digital-Ophthalmology-Clinical-Record-System/issues).
2. Provide a clear description, steps to reproduce, and screenshots if applicable.

---

Thank you for helping make ophthalmic clinical software better! 👁️✨
